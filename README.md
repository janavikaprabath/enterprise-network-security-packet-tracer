# Enterprise Network Configuration and Security Implementation Using Cisco Packet Tracer

## Overview

This project demonstrates the design, configuration, and analysis of a secure small-scale enterprise network using **Cisco Packet Tracer**. The network consists of wired and wireless devices connected through a wireless router, enabling secure communication between local devices and external network resources.

The project focuses on implementing fundamental networking concepts such as IP addressing, DHCP configuration, routing, switching, wireless communication, DNS resolution, and network connectivity verification. It also introduces essential cybersecurity concepts including secure wireless access, network authentication, firewall awareness, and basic network troubleshooting.

This project was completed as part of a **Cybersecurity Internship** to gain practical experience in enterprise network configuration and security implementation.

---

## Objectives

- Design a small-scale enterprise network topology.
- Configure a wireless router for secure communication.
- Implement Dynamic Host Configuration Protocol (DHCP).
- Connect both wired and wireless client devices.
- Configure IPv4 addressing.
- Verify end-to-end network connectivity.
- Access network services through the simulated Internet.
- Understand enterprise networking and basic cybersecurity principles.

## Project Workflow

### 1. Network Design

Designed a small enterprise network using Cisco Packet Tracer consisting of wired and wireless devices connected through a wireless router.

### 2. Router Configuration

Configured the wireless router with appropriate network settings and enabled DHCP for automatic IP address allocation.

### 3. Client Configuration

Connected desktop computers using Ethernet cables and configured the laptop to join the wireless network securely.

### 4. IP Address Assignment

Verified that all client devices successfully received IPv4 addresses, subnet masks, default gateways, and DNS server information using DHCP.

### 5. Connectivity Verification

Tested communication between devices using:

- Ping
- Packet Simulation
- Router Web Interface
- Web Browser

### 6. Internet Access Verification

Successfully accessed the hosted web server through the simulated Internet, confirming proper routing and DNS functionality.
